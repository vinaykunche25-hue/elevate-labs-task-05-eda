# Task 5 — Exploratory Data Analysis (EDA)

## Objective
Extract insights using statistical and visual exploration, as described in the Elevate Labs Task 5 brief.

## Dataset
`data/customer_orders_eda.csv` is a **synthetic learning dataset generated for this task**, not real company data. The brief allows a relevant dataset of your own choice.

## Deliverables
- `notebooks/eda_analysis.ipynb` — Jupyter Notebook
- `reports/eda_findings_report.pdf` — PDF findings report
- `data/customer_orders_eda.csv` — dataset used
- `visualizations/` — exported plots
- `README.md` — project explanation

## How to run
1. Install dependencies with `pip install -r requirements.txt`.
2. Open `notebooks/eda_analysis.ipynb` in Jupyter Notebook or VS Code.
3. Run cells from top to bottom.

## EDA coverage
- `.info()`, `.describe()`, missing-value counts and duplicate detection
- Histogram, boxplot, scatterplot, correlation heatmap and scatter matrix
- Summary observations and limitations

## Limitation
The dataset is synthetic for practice. Do not present findings as evidence about a real business.
